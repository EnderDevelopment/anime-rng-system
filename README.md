# Anime RNG System for Roblox Studio

This project contains the necessary scripts for an Anime RNG system in Roblox Studio. It includes a complete interactive UI for rolling, displaying random results, managing character inventory, viewing collections, and equipping characters. The system features rarity tiers, roll animations, rarity-based probabilities, and a basic pity system. The UI is designed with a modern anime-inspired aesthetic, optimized for both PC and mobile.

## Install

1. Create a new Roblox game or open an existing one in Roblox Studio.
2. Create a new folder named `AnimeRNGSystem` in the `ServerScriptService`.
3. Place the `MainScript.lua` file inside the `AnimeRNGSystem` folder.
4. Create a new folder named `Modules` inside the `AnimeRNGSystem` folder.
5. Place the `RarityModule.lua`, `InventoryModule.lua`, `AnimationModule.lua`, and `PitySystemModule.lua` files inside the `Modules` folder.
6. Create a new folder named `UI` in the `StarterGui`.
7. Place the `MainUI.lua` file inside the `UI` folder.

## Use

1. The RNG system will automatically initialize when a player joins the game.
2. Players can roll for random characters using the UI.
3. The system includes rarity tiers, animations, and a pity system.
